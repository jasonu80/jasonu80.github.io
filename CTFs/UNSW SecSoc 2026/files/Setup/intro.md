here's some useful info that'll be helpful if you're new to CTFs


**what is a CTF?**
a Capture The Flag (CTF) is a cybersecurity competition with a series of challenges for you to solve. Each challenge will reward you with a 'flag' once you've solved it. Flags can be submitted to earn points on the scoreboard.

**what is a flag?**
a flag is just a string of text that you get when you solve the challenge.
all flags in this CTF will have the format "SCONES{...}". keep note of this format - it might help you solve some challenges!

**how do i start?**
the best way to start CTFs is trying the challenges! unlike a lot of competitions and exams though, CTFs involve a lot of *research*.

CTFs are designed to showcase and educate about vulnerabilities, so a big part of that is your own independent research. it is very common and probably even expected that you'll need to make multiple google searches to understand the challenge or a certain exploitation method. 

here's a few resources you might find useful to start CTF as well as set up tools!
- https://CTF101.org/
- https://opensource.com/article/21/8/linux-terminal

**in particular, if you are on a Windows computer we highly recommend installing WSL (https://learn.microsoft.com/en-us/windows/wsl/install)**. this will give you a Linux system which is much more capable when it comes to solving challenges.

**challenge categories**
you might have noticed that there's a few challenge categories, like `pwn` and `crypto`. you can expect different things from each of these categories. here's a quick guide to get you started:

- `beginner`: these challenges are a collection of easy challenges from the other categories. you can see which category a beginner challenge is from by hovering over the second category icon. they're intended to introduce you to that kind of challenge. solving these challenges will still require some effort and research!
- `osint/irl`: OSINT stands for open source intelligence! you need to use the internet and research skills to locate or find information to help you solve these challenges! the IRL challenges involve something you need to physically do at SCONES.
- `web`: these challenges focus on vulnerabilities in websites! you just need a browser to get started.
- `forensics`: forensics challenges require you to do some digging or investigation to uncover a secret in a file or system.
- `crypto`: short for cryptography, these challenges deal with how cryptographic protocols may be weak. requires a solid knowledge of maths and number theory in particular.
- `pwn`: alternatively called binary exploitation, these challenges deal with vulnerabilities in compiled programs, usually written in C. this category deals with how data is stored and how programs are run at the lowest level!
- `misc`: these are challenges that don't quite fit into any other category.
- `hardware`: these are beautiful challenges written by our projects portfolio! all the flags in this challenge are on the SCONES badge - happy hacking!
- `rev`: these are reverse engineering challenges! figure out whats going on with the binaries or scenario presented to you, and it will present a flag to you!

**what if i need help?**
if you're stuck on something please come up to us! there'll be someone from the CTF team in the CTF room throughout the event. since this is a competition we won't be able to directly help you with solving the challenges, but we're happy to help with things like connecting to the challenges or setting up tools.
